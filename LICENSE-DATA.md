# Generated-data licensing

The generator source code in this repository is licensed under the MIT License.
The generated domain files retain the licenses and attribution requirements of
their upstream data. There is no single license covering every generated file.

- `fake-news.txt`, `gambling.txt`, and `social-media.txt` use category sources
  described by StevenBlack/hosts as MIT-licensed.
- `porn.txt` and `porn-extended.txt` contain data from Bon-Appetit/porn-domains
  and are distributed under CC BY-SA 4.0 with the required attribution. The
  complete license text is in `LICENSES/CC-BY-SA-4.0.txt`.
- `ads-malware.txt` combines upstream datasets under several licenses. Consult
  `SOURCES.md`, the generated manifest, and StevenBlack/hosts before reuse.

This summary is provided for provenance and is not legal advice. If an upstream
license conflicts with this summary, the upstream license controls.
